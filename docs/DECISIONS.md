| D-037 | «Точка на воде»: long press / right click anywhere (and a tap on water) opens an estimate for the coordinate. Weather and rules are exact for the point; species come from the class of water, described places of the same class within 30 km and GBIF/iNat records within 20 km; the chance is a RANGE (model run at the neighbours' min and max rank), or absent with the reason when no same-class neighbour exists. A synthesized `Spot` feeds the unchanged model. | Anglers stand where no spot is described; an honest interpolation beats an empty sheet, and a range with sources beats a fake point value. Same-class matching stops a pond from inheriting Irtysh зандер scores. | Point value from IDW over all spots; a separate «pin» screen. |

| D-041 | «С вашим ящиком»: coverage of a species' methods by the box is computed per role group (снасть / оснастка / насадка); full = every group present has an owned class, partial = some, unknown when the texts name no glossary item.
